One-time setup: configure OAuth in Google Cloud Console, add credentials to .env, set web_public_url: http://127.0.0.1:8080 in config.yaml, restart the server, then use the button below. See README for full steps.

Google Cloud Console steps
  1. Create a project (or use your existing one)
  2. APIs & Services → Library → enable YouTube Data API v3
  3. OAuth consent screen → External → stay in Testing (no need to publish)
  4. Add your YouTube Google account email under Test users
  5. Credentials → Create OAuth client ID → Web application
  6. Authorized JavaScript origins: leave empty
  7. Authorized redirect URI: http://127.0.0.1:8080/auth/youtube/callback (LAN IPs like 192.168.x.x will not work)
  8. Add to .env and restart ytdigest web: 
    YOUTUBE_OAUTH_CLIENT_ID=your-client-id.apps.googleusercontent.com
YOUTUBE_OAUTH_CLIENT_SECRET=your-client-secret

Pi users: connect locally on your dev machine first (web_public_url: http://127.0.0.1:8080), authenticate once, then copy data/ to the Pi. See README.
